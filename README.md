School Almanac – Backend API

School Almanac is a School Management System backend API developed using ASP.NET Core. It is designed to manage school-related information and provide API services for different school management operations.

🚀 Project Overview

School Almanac is a backend project built to organize and manage school information efficiently. It follows a structured architecture with separate layers for Models, ViewModels, Repositories, Services, and API.

🛠️ Technologies Used

- C#
- ASP.NET Core Web API
- Entity Framework Core
- RESTful APIs
- SQL Database
- JWT Authentication

⚙️ Installation & Setup

1. Clone the repository

git clone https://github.com/arshansari78/School-Almanac-LoopBridge-.git

2. Open the project

Open "LoopBridge.slnx" in Visual Studio.

3. Configure Database

Update the database connection string in "appsettings.json" according to your local database configuration.

4. Restore NuGet Packages

dotnet restore

5. Run the project

dotnet run --project LoopBridge.Api

🎯 Project Goal

The main goal of this project is to simplify school management operations by providing organized backend services and APIs for students, teachers, parents, and school administration.
